# 数字逻辑与计算机组成——课程大实验

共六个实验，用Logisim软件，逐步实现一个包含RV32I全部指令的完整的CPU。

## 实验一：数字逻辑基础

- Logisim软件的使用
- 门电路的实现
- 子电路的设计和应用
- 数字系统设计的基本设计方法

## 实验二：组合逻辑部件设计

- 译码器、编码器、数码管等组合部件的设计方法
- 1位加法器、4位串行加法器的设计方法。
- 汉明码编码和纠错的设计方法。
- 桶形移位器的设计方法。

## 实验三：**同步时序部件设计**

- 时序逻辑电路设计的基本方法。
- 计数器和移位寄存器的设计方法和应用。
- 无符号乘法器、寄存器堆、数字时钟的设计方法。
- 数字系统的设计方法

## 实验四：运算部件设计

- 先行进位部件CLU和先行进位加法器CLA的设计方法。
- 32位快速加法器和标志位的设计方法。
- 32位桶形移位器的设计方法。
- RV32I算术逻辑部件的设计方法。

## **实验五：存储器及数据通路设计**

- 利用ROM组件实现指令存储器的设计方法。
- 掌握实现RV32I存取指令的设计方法。
- RV32I下地址逻辑部件、指令译码、反汇编的设计方法，RV32I立即数扩展器的设计方式
- 根据RV32I指令执行过程，掌握RV32I运算类指令数据通路的设计方法
- 跳转控制器的设计方法、

## 实验六：单周期CPU设计与测试

- RV32I控制器的设计方法。
- 多输入多输出组合逻辑部件设计方法。
- 最小风险法设计方法。
- RV32I单周期CPU的设计方法。
- 理解冯诺依曼程序存储和程序控制的思想
