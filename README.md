## 在实验环境中打开终端执行以下代码, 提交即可
#### 注: 把最后的lab4改成正在做的实验
#### 注: 一次实验只需运行一次
```shell
git clone https://github.com/ihxnan/educoder.git
cd educoder
# 备份当前代码
mkdir /data/workspace/myshixun/back
mv /data/workspace/myshixun/*.circ /data/workspace/myshixun/back
# 改成正在做的实验
cp lab4/* /data/workspace/myshixun/ 
```
### 一行命令版
```shell
git clone https://github.com/ihxnan/educoder.git && cd educoder && mkdir /data/workspace/myshixun/back && mv /data/workspace/myshixun/*.circ /data/workspace/myshixun/back && cp -r lab4/* /data/workspace/myshixun/
```
